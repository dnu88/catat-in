# Mobile Report and Budget Wallet Polish Design

Goal: Apply option B, structured product-UI polish, to Reports and Budget Wallet creation.

Design:
- Reports budget wallet entry keeps the action button readable by using a stable row with a flexible text column, tighter supporting copy, and a non-wrapping manage pill.
- Reports line chart becomes more proportional with a wider SVG viewport, taller plotting area, subtle horizontal guides, and points calculated from the chart height instead of hard-coded cramped values.
- Budget wallet icon choices use Phosphor-backed Kaswise icons mapped to real budget categories: food & beverage, transport, sport, recreation, bills, groceries, investment, gift, and other expenses.
- Budget wallet colors expand from six to twelve curated theme-compatible choices for both light and dark modes.

Quality bar: production polish for current MVP flow, preserving existing navigation and service behavior.
