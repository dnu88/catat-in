# Kaswise Privacy Policy

Last updated: 2026-06-14

This document is the canonical in-repo privacy policy source for Kaswise. Public web/legal pages and in-app links should stay aligned with this text.

## Overview

Kaswise is a personal finance application that helps users record transactions, manage wallets, monitor budgets, review reports, and use optional premium features. Because financial data is sensitive, Kaswise is designed to limit access to each user’s own account data and to use infrastructure providers only as needed to operate the service.

## Data Kaswise collects

Kaswise may collect and process the following categories of data:

1. Account data
- Email address and authentication identifiers
- Profile metadata such as display name, avatar choice, and language preference
- Session and access-control data needed to keep the account secure

2. Finance data provided by the user
- Transactions, notes, merchants, categories, wallets, budgets, bill reminders, reports, and related household/group finance data
- Preferences that affect how cashflow, categories, reminders, and summaries are displayed

3. Imported or generated data
- Receipt images or imported files when the user chooses scan/import features
- OCR/import outputs and parsing results used to help prefill finance records
- AI-generated summaries or insights based on user finance data when such features are used

4. Payment and entitlement data
- Plan status, payment references, entitlement status, and premium access metadata
- Kaswise does not store raw card credentials inside the app codebase; payment handling for web/PWA may involve external processors

5. Technical and operational data
- Basic device/app diagnostics, timestamps, request metadata, and logs required to operate, troubleshoot, prevent abuse, and secure the service

## How Kaswise uses data

Kaswise uses data to:
- authenticate users and protect account access
- save and display finance records and reports
- deliver reminders, budgets, household/group features, and premium entitlements
- process imports, OCR, and AI-assisted finance workflows requested by the user
- investigate errors, abuse, fraud, or security incidents
- comply with legal obligations and resolve support requests

## Required vs optional data

Required data generally includes:
- account/authentication data needed to create and secure an account
- finance records the user intentionally saves

Optional data generally includes:
- profile photo/avatar customizations
- receipt images, attachments, and scan/import data
- AI-assisted inputs or premium workflow data only when the user chooses those features

If optional data is not provided, related features may be limited or unavailable.

## Service providers and infrastructure

Kaswise may use third-party infrastructure providers to operate the product, including services for:
- authentication, database, and storage (for example Supabase)
- backend/API processing
- AI or import-related processing when the user requests those features
- payment processing for web/PWA subscription flows

These providers process data only to help deliver Kaswise functionality or support operational security.

## Data sharing

Kaswise is not designed to sell personal financial data to third parties. Data may be disclosed only when reasonably necessary to:
- operate the service through processors/infrastructure providers
- comply with law, regulation, legal process, or enforceable government request
- investigate fraud, abuse, or security incidents
- protect Kaswise, users, or the public from harm

## Data retention

Kaswise retains data for as long as reasonably needed to:
- keep the user account functional
- provide requested finance history and app features
- maintain service integrity, backups, auditability, and abuse prevention
- satisfy legal, tax, accounting, or security obligations where applicable

If a user requests account deletion, active account access should be removed and user data should be deleted or anonymized according to the applicable deletion workflow, except where limited retention is required for legal, security, fraud-prevention, or operational reasons.

## Account deletion and user control

Users can review Kaswise’s deletion path from inside the app via the Account Deletion link in Settings. Kaswise may support either:
- a deletion request workflow that is processed by support/operations, or
- a stronger self-service deletion flow when implemented and approved

For the current Track A path, signed-in users can submit an authenticated deletion request from mobile Settings, while public/legal pages still provide a no-login fallback path through the Kaswise account deletion page and support contact.

## Security

Kaswise uses authentication and per-account access restrictions and aims to protect stored data from unauthorized access. No system can guarantee absolute security, so users should also protect their device, email account, and login credentials.

## Children

Kaswise is intended for general personal-finance use and is not designed specifically for children. If you believe personal data was provided inappropriately, contact support.

## Policy updates

Kaswise may update this policy as product features, infrastructure, or legal requirements evolve. The latest approved version should be reflected on the public legal page linked from the app.
