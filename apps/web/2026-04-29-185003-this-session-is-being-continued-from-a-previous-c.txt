  ---
  Fixed bugs:

  1. Tambah/Edit Anggaran — listBudgets was using where + orderBy together which
   requires a Firestore composite index that didn't exist. Removed orderBy from
  the Firestore query and sort results in JS instead.
  2. Edit Transaksi — The updateTransaction action existed in the store but was
  never exposed in the UI. Added ✏️ button to each transaction row and converted
   AddTxModal into a shared TxModal that handles both add and edit modes
  (pre-fills all fields from the existing transaction).
  3. Edit Wallet — Same pattern as transactions. Added ✏️ button to each wallet
  card and converted AddWalletModal into a shared WalletModal for add/edit.
  4. Logout flash — When the user clicks logout, isLoading was set to true in
  the auth store but RequireAuth didn't check it. This caused the app shell to
  briefly flash before redirecting. Now RequireAuth shows the loading splash
  screen whenever isLoading is true, so the transition is clean.
